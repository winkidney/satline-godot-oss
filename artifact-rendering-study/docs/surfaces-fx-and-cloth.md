# Saltline 的湿地、水面、特效与近景服装

2026-11-14，静态源码研究。以下“已确认”表示活动脚本中存在实现及调用关系，不表示本轮已运行、看过画面或测过性能。原件为 [saltline.original.html](../source/saltline.original.html)，可读版本为 [bundle-1.js](../source/extracted/bundle-1.js)。所有行号都指可读版本。`legacy-v8` 脚本的类型是 `application/octet-stream`，不是这里的分析对象。

## 1. 湿地是多尺度材质组合

地表不是简单地把一张粗糙度图调低。`Vg()` 在 L56729 建立整套数据和网格，`Nw()` 在 L56080 将它们接进 `MeshStandardMaterial`。

| 层 | 已确认的源实现 | 作用 |
| --- | --- | --- |
| 非重复的大尺度控制 | `SP()` L55521、`Dw()` L55552；覆盖 80 m 范围的 RGBA 掩码 | R 为相对水位/凹地，G 为湿润分布，B 为油污，A 为磨耗变化 |
| 可重复的细节 | `Lw()` L55599 | 周期噪声及其有限差分坡度，RGBA 分装多个细节与坡度通道 |
| 道路标记 | `Fw()` L55653，Canvas 2D 画线、文字、警示条和轮胎痕 | 低频位置与美术设计单独保存，不把整张地面都做成高分辨率独占颜色图 |
| 数据采样 | `Hg()` L55639；`gBicubic()` L55908 | 数据图使用无颜色空间、mipmap 和各向异性过滤；放大时用 4 次双线性采样组合成 B-spline 双三次过滤 |
| 程序高频 | `AP` L55938 | 世界坐标下的接缝、裂缝、细小油漆缺损，避免近看出现控制图像素块 |

地表片段中 `fwidth` 调整接缝和标记的边缘宽度；更细的破损噪声随距离退场。这里的世界坐标适合静态地面。迁移到会拉伸的袜子时应改用稳定材料坐标，否则花纹会在布面移动时滑动。

湿润使用连续区域而不是硬切开关，见 L56003–56055。水位与掩码决定积水、浸透带、潮湿边和干燥区，它们共同改变：

- 基础色变暗，积水深处增加浑浊底色。
- 粗糙度由干燥约 `0.74`，过渡到潮湿、浸透、水膜，最后积水约 `0.055`。
- 积水压平地表颗粒坡度，再叠加风波和雨圈；远处减少雨圈细节、略增粗糙度。
- L56130 将积水的介质高光颜色向 `0.075` 混合。这是该示例的美术参数，不是测量得到的水或尼龙光学常数。

对丝袜有用的是“一份状态同步驱动颜色、覆盖率、粗糙度和法线”的组织方式。潮湿尼龙的真实变化应另作校准，不能直接照搬沥青的变暗比例或水面粗糙度。

## 2. 反射是镜像相机，不是 SSR

`Uw()` L56157 建立半浮点、线性 HDR、带 mipmap 的反射纹理。L56209 起反转主相机高度和观察方向，把相机镜像到水平面下方；L56233 起修改投影矩阵，做斜裁切平面。反射前临时隐藏地面、海面和雨水特效，再调用 `renderWorld()`，之后恢复可见性。

调用关系在 L56762–56763 很清楚：反射纹理绑定 `m.uniforms`，即 apron 地面；海面 `x` 只是反射捕获时被隐藏的对象。不能因此说海面也使用了这个平面反射。

地表的 `RP` L56052–56078 用投影矩阵得到反射 UV，再以坡度扭曲 UV。它根据材质粗糙度、积水权重和视角选择 mip LOD；潮湿沥青额外做纵向拉伸的模糊，积水则更清楚。反射最终替换的是环境镜面辐射 `radiance`，仍经过底层 PBR 的反射响应。

Godot 可先评估 `Sky` / `ReflectionProbe` 是否足以表达棚景亮带。若目标确实是平面镜像，另建 `SubViewport` 与镜像 `Camera3D`，用自定义 shader 投影采样；斜裁切、更新频率、剔除层和分辨率需要专门实现。单个 ReflectionProbe 不能等价替代平面镜。对丝袜本体，优先使用稳定的环境反射和纱线 BRDF；该地面镜像技术适合展示台或地板。

## 3. 海面将几何波与法线波分开

L56259 的 `Og` 有 4 组波，L56265 的 `Bw` 有 7 组更细的波。每组方向归一化，波数为 `2π/λ`，频率按 `sqrt(9.81*k)` 计算。

- `CP` L56289 把主波写进顶点 shader，包含竖直正弦位移和水平余弦位移，属于参数波形。
- `kP` / `PP` L56294–56303 为片段生成主波和细波坡度，并叠加几组滚动噪声法线。
- `Ow()` L56363 建立近处密、远处疏的非均匀海面网格，远处逐渐减小几何波幅。
- `zP` L56311 用到岸墙与船体的解析距离生成泡沫/浮垢，调整颜色、粗糙度和遮蔽。风斑改变坡度、亮度与高光强度。
- L56457 限制直射镜面峰值，再按太阳方位和波纹调节水面碎光。`DP` L56347 给远处海面叠加方向相关的地平线雾色。

该海面材质是非透明 `MeshStandardMaterial`，源码这里没有屏幕折射或水深透射采样，也没有流体求解器。`Hw()` L56282 在 CPU 上计算同类高度，向游戏提供 `seaHeight()`；这仍是解析波，不是可与布料求解互换的物理方案。

Godot 对应是 spatial `vertex()` 位移、同一波函数的解析 normal、按距离过滤微法线，再接入标准受光。可借鉴到丝袜的原则是把轮廓级形变交给几何，把亚像素细节交给法线/平均 BRDF。海浪参数本身不适合用于布料拉伸。

## 4. 雨、水花和烟尘依靠可控的视觉近似

### 雨和水花

雨 shader `LP` L56500 以固定种子和时间计算雨滴位置，围绕相机循环复用包围盒。雨线沿速度拉长，宽度至少约一个屏幕像素，并按放大量补偿亮度。4 个室内盒与 8 个天窗开口负责阻止雨线穿屋；檐口滴水使用约 7 m 的解析自由落体。雨滴颜色用太阳方向的前向散射相位与环境色组合。

`NP` L56549 生成短寿命水花，通过积水掩码和室内盒决定是否出现。`gRipple()` L55920 则在地面法线中生成扩张衰减的雨圈。三者没有逐滴共享碰撞状态，属于相互一致的程序表现。`Gw()` L56614 建立实例化雨线和水花网格，使用透明加法混合、关闭深度写入。

### 烟、火、火花与曳光

`Vv()` L57708 为四边形批次分配 `aPos/aAxis/aCol/aMisc` 实例数据。`OP` L57585 提供三种几何排列：面向相机、沿速度拉长、贴表面。`u1` L57868 用 TypedArray 池更新寿命、运动和排序，L58781 建立受光池与加法池。L58745 的容量是 `1400` 与 `3200`，这只是上限配置，不能当作实测同时可见数或性能数据。

受光粒子 `VP` L57660 把整体球形假法线与 atlas 中的 billow 法线组合，算包裹漫反射、上下环境色和逆光薄边散射。其阴影权重来自发射时的简化射线检查，见 L58831，不能等同于烟体逐像素自遮挡或体积阴影。

烟和有形状的火焰使用预乘 alpha 混合，L57684 明确保留前后遮挡与火焰轮廓；火花等光点另走加法 shader `WP` L57697。同一特效可以组合两种池，但不能认为所有亮效果都是 bloom 或 additive。

`softFade()` L57651 从场景深度恢复视空间深度，按与粒子深度的距离平滑淡出交界。启用条件在 L57788–57806，限主相机、有效且非正在写入的深度副本，并能由 `fxsoft=0` 关闭。软粒子功能存在，不代表所有渲染路径都实际启用它。

Godot 可用 `GPUParticles3D` / `ParticleProcessMaterial` 管理寿命、重力、随机和方向，自定义 spatial shader 实现 atlas、假法线、软交界与散射；需要显式 CPU 控制或固定池时再考虑 `MultiMesh`。后者是整体空间边界，需规划 AABB 和分区。[粒子参数](https://docs.godotengine.org/en/stable/tutorials/3d/particles/process_material_properties.html)、[MultiMesh](https://docs.godotengine.org/en/stable/classes/class_multimesh.html)。

软交界要用 Godot 当前 viewport 的 `hint_depth_texture` 和 `INV_PROJECTION_MATRIX` 重建深度。Godot 4.3+ 使用 reversed-Z，Forward+/Mobile 与 Compatibility 的 NDC 范围也不同，不能照搬这里的 WebGL near/far 公式。[官方深度重建](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html#depth-texture)

### 弹痕与碎片

`Yw()` L57132 在 Canvas 中画弹痕、烧焦和烟灰 atlas，返回颜色、ORM 与由高度推导的 normal。`Jg` L58595 把四边形沿命中法线摆放，L58704 的微小法线偏移配合 polygon offset 防止重合闪烁。其弹孔是覆盖面，不是把底层模型穿孔。

`jg` L58275 用实例化网格画真实碎片，但运动只是重力、地板高度和简化弹跳；这种小碎片池可借鉴到服装碎屑，附着于袜子的残余纱线仍应保留自身连接和约束。

Godot 的 `Decal` 可以投射颜色、normal 与 ORM，适合污迹或湿印；真实破洞仍需影响几何或覆盖/深度/阴影。变形衣物上的固定花样也可直接在材料坐标中混合，避免投射位置漂移。[Godot Decal 官方教程](https://docs.godotengine.org/en/stable/tutorials/3d/using_decals.html)

## 5. 手套与衣袖是最值得直接借鉴的部分

`QE()` L75282 创建非金属 `MeshStandardMaterial`，通过 `onBeforeCompile` 加入 `armSurface()` 与 `armMicro()`。它修改 albedo、roughness 和 bump，仍使用标准材质光照。此局部模块没有给衣袖实现专用纱线各向异性 BRDF。

### 稳定的材料坐标

L75296–75301 从顶点属性读取 `aRest` 与 `aHand`，送到 `vArmRest/vArmHand`。`armSurface()` L75171 依据手部区域、轴向位置、环向角度和关节长度划分掌面、背面、指尖、加固区、橡胶护块、袖口、绑带、反光带与缝线。大部分细节直接在静止材料域生成，不依赖当前世界坐标。

这适合迁移到袜口、足尖加密区、纵向接缝和蕾丝分区。应在袜子本身的材料参数域重建，不复制手指/手掌的几何常量。

### 六种材质细节与导数过滤

`armMicro()` L75251 用 `kind` 混合普通织纹、皮革颗粒、橡胶、针织罗纹、防雨外壳和反光带。三平面权重来自静止法线平方并归一化，织纹由不同坐标平面的正弦乘积生成。它包含方向性的颜色/凹凸图案，但这不等于各向异性高光或真实逐纱线模型。

`px = max(length(dFdx(p)), length(dFdy(p)))` 估计每像素覆盖的材料长度，`0.18–0.50 mm/px` 区间让微细节渐隐。中低频色差和粗糙度变化继续保留。这个物理尺度下的退出策略，比单纯增加贴图分辨率更适合细密袜纹。

### 雨珠、缝线和 bump 的边界

L75260 的雨珠在衣袖轴向/环向坐标中布置；两级网格分别约 `8.5 mm`、`4.1 mm`，球冠高度叠到 `h`，同时把局部 roughness 向 `0.07` 过渡并略微变暗。它是静态分布受湿度控制的光学表现，没有水滴合并、沿重力滑动或流体质量守恒。

`armBump()` L75276 根据视空间位置与高度导数重建法线。缝线、罗纹和雨珠由此改变受光，不会自动改变轮廓、投影、碰撞或织物质量。该模块不能证明示例实现了丝袜受力、破洞、脱卸或布料自碰撞。

## 6. 武器材质展示了“语义遮罩 + 多尺度微细节”

`Bz` L70348 定义阳极氧化、磷化、聚合物、氮化和哑光衬垫几组。`_E()` L70488 向标准材质加入属性 `aSurf`，在 `Oz` L70398 将其解释为边缘、凹腔、裸露底材和磨损区。不是给每个部件铺一张独立的大颜色贴图，而是让几何语义遮罩控制材料反应。

L70402 用 `fwidth` 测每像素材料尺寸；枪身划痕、颗粒、握把凸点都在低于分辨率前淡出。握把约 `1.15 mm` 的程序凸点退场时保留平均粗糙度变化。雨水 L70465 同时改色、roughness 和由高度导出的 bump；凹腔遮罩还压低间接与部分直接光。这是可控的磨损/潮湿模型，不能据此断言符合严格能量守恒。

补充的瞄具玻璃 `ME()` L70138 以观察夹角构造标线、Fresnel、环境天空反射、余弦薄膜变色、灰尘和指印。L70210 所谓薄膜是艺术近似，没有光谱波长与真实膜厚计算。此法可用于装饰性珠光探索；不应当作黑色尼龙默认光学模型。

## 7. 对 `stocking-lab` 的迁移顺序

这些是设计建议，未改动目标项目，也未运行验证。

| 优先级 | 可学习的方法 | 现有接入点与约束 |
| --- | --- | --- |
| 高 | 材料坐标稳定、毫米尺度区域与细节 | 保留 [fabric_vertex.gdshaderinc](../../stocking-lab/shaders/fabric_vertex.gdshaderinc) 的变形及切线重建；沿袜体 chart/UV 定义，不改成静态世界投影 |
| 高 | 亚像素细节退出、低频平均量保留 | [nylon_body.gdshaderinc](../../stocking-lab/shaders/nylon_body.gdshaderinc) 已有导数足迹、coverage/glint 和 normal variance；研究它的阈值与平均覆盖保持方式，避免重复叠加另一套 LOD |
| 高 | 同一状态驱动多种材质属性 | 在 [fabric_optics.gdshaderinc](../../stocking-lab/shaders/fabric_optics.gdshaderinc) 的密度/视角模型旁组织湿润等状态，但保留尼龙专用的覆盖率与各向异性响应 |
| 中 | 缝线/罗纹/雨珠的材料域程序描述 | 先作可关闭的外观层，配合 bump 与 roughness；需要影响轮廓时再增加真实几何 |
| 中 | 局部污迹、磨耗与区域化着色 | 袜口、足尖、损伤边缘分别有语义遮罩，避免整面随机噪声；破洞逻辑继续负责显示/深度/投影同步 |
| 低 | 湿地平面镜像、雨和烟尘 | 适合作为展示场景；先确认画面目标，再评估额外相机与透明 overdraw 成本 |
| 低 | 瞄具的薄膜色彩近似 | 仅作独立珠光/饰物实验，不替代纱线 BRDF |

针对丝袜目标项目，后续再分别验收远近镜头的摩尔纹、拉伸时图案漂移、切线高光连续性、透明交叠、真实洞口阴影、湿润参数与展示灯光。原作截图和有限GPU计时已补入[实机报告](runtime-findings.md)，丝袜专用动态项目仍未验证。
