# 审阅图集来源

这三张图集将项目内既有历史截图缩放排版，供选景审阅；不是本轮新录素材，不证明两侧操作同步或所有条件一致。原作及其衍生素材的公开授权仍待核实。

每行从左到右分别为原版、Godot。以下链接指向用于制作图集的原文件；实际采集条件以相应证据记录为准。
