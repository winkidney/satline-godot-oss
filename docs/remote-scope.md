# 仓库资料范围

本机完整项目保留原始录像、成片、研究图像、预烘焙对照资产及其历史。GitHub 仓库保留游戏运行所需的 `saltline-godot/assets/`、兼容引擎、代码、研究文本、测量记录和视频制作配方；视频、录屏及非运行所需的二进制素材不上传。仓库不使用 Git LFS。

缺少本机素材时，视频剪辑工程不能直接导出完整影片，官方内建对照也缺少预烘焙贴图；主游戏的运行入口见根目录 README。声音参考、逐字稿和克隆数据始终不进入仓库。

精简版本的游戏资源导入与启动结果见[独立副本验证](remote-runtime-validation.md)。
